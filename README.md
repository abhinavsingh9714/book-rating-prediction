# Book Rating Prediction

This project implements an item-item collaborative filtering model to predict how users would rate books they haven't rated yet.

## Structure
- `src/`: Core modules for loading, modeling, and evaluation
- `experiments/`: Scripts to run batch experiments
- `notebooks/`: Exploration and visualization
- `main.py`: Entry point for training and evaluation

## Setup
```bash
pip install -r requirements.txt
python main.py
```
